## 📌 Features

- 🚨 **Emergency SOS** — Quick access to emergency contacts and helplines
- 🔍 **Scam Checker** — Identify and report online scams and fraud
- 👩‍👩‍👧 **Community** — Safe space for women to connect and share experiences
- 📚 **Digital Awareness** — Cybersecurity education and safety tips
- 💜 **Women Care** — Mental health and wellbeing resources
- 🔐 **Firebase Authentication** — Secure user login and registration
- 📱 **Fully Responsive** — Works on all devices

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/laxmanalucky090-ux/CyberRakshas.git
cd CyberRakshas

# Open in browser
open index.html
# or just double-click index.html
```

No build process needed — pure HTML, CSS, JavaScript!

## 🌍 Impact

CyberRakshas addresses a critical need in India — digital safety for women. Features include:

- 📞 Direct access to women's helpline numbers (1091, 181)
- 🛡️ Real-time scam detection education
- 🤝 Community support network
- 💡 Cybersecurity awareness in simple language
